QGIS

    
Layer → Add Layer → Add Raster Layer, source type Protocol: HTTP(S) (or File on the lab storage), then paste the file address. QGIS reads the overviews first, so the whole peninsula opens quickly. Set the band rendering to Singleband pseudocolor on band 1 and remember the values are mm/month × 10.


    
Browse tiles

    
The map on this site does not use pictures of the data. It reads 8-bit numeric tiles (one PMTiles file per month, Web Mercator, zoom 3–12) in which each pixel stores ET in whole mm/month, and colours them in the browser. They are meant for looking, not for analysis: they are resampled and rounded. Use the GeoTIFFs for any calculation.

  







 

  

    
About the data

    
Monthly evapotranspiration (ET) at 30 m for the Korean Peninsula, April 2013 to August 2026, estimated with Prithvi-OpenET-Tower.


    
The model

    
Prithvi-OpenET builds on Prithvi-EO-2.0, a geospatial foundation model pretrained on Harmonized Landsat and Sentinel-2 (HLS) imagery. It was first trained over the conterminous United States to reproduce the five ensemble members of OpenET from HLS reflectance, and then adapted to observations from 283 flux-tower sites around the world. The adapted model is Prithvi-OpenET-Tower, and it made these maps.

    
The model predicts the ratio of ET to reference ET. Multiplying that ratio by FAO-56 reference ET from MERRA-2 gives ET in mm per month. It uses no thermal imagery.


    
Inputs

    

      
        
Surface reflectanceHLS v2.0 Landsat (L30) and Sentinel-2 (S30), six bands, one monthly composite per pixel from clear observations

        
WeatherReference ET and vapour-pressure deficit from MERRA-2; clear-sky shortwave radiation computed on Copernicus GLO-30 terrain

        
Terrain and soilElevation (Copernicus GLO-30), topographic wetness index (MERIT Hydro), available water capacity (SoilGrids 2.0), aridity index (CGIAR)

      
    

    
Every input is available worldwide, which is why the same model can be run for other regions on request.


    
How these maps were made

    
    
      
  • Each map is the mean of nine models trained on different groups of flux towers. Their spread is kept as a second band.
    • 
      
  • The model ran in overlapping 224-pixel windows that were blended together, and a correction removed the steps that MERRA-2 grid cells would otherwise leave in the map.
    • 
      
  • A pixel with no clear-sky observation in a month is left empty. Nothing is gap-filled.
    • 
      
  • South and North Korea were processed separately and merged on one 30 m grid.
    • 
    


    
Read this before you use the numbers

    
    
      
  • 
      
  • 
      
  • Training period. The model was trained on 2016–2024. Months before 2016 and after 2024 are extrapolations in time and are marked as such on this site and in each file.
    • 
      
  • Gaps. Empty pixels are common in the summer monsoon and in 2013–2015, when only Landsat was available. A regional mean covers only the pixels that were observed, so read it together with the share of land observed.
    • 
      
  • 30 m is the grid, not the accuracy. Accuracy at single pixels and single fields has not been verified, and many Korean fields are smaller than a pixel.
    • 
      
  • North Korea. There are no flux towers to check the estimates against.
    • 
      
  • Model spread is not total uncertainty. Band 2 shows only how much the nine models disagree.
    • 
      
  • Missing month. September 2025 was not produced because an input was unavailable.
